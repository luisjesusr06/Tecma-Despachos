TECMA / DESPACHOS

De la carpeta al teléfono

No necesitas instalar programas ni saber programar. Harás la publicación una vez desde tu computador; después podrás abrir la app desde su ícono.

1. Prepara los archivos

  1. Descarga Tecma_Despachos.zip.
  2. En Windows, haz clic derecho sobre el ZIP y elige Extraer todo.
  3. Abre la carpeta extraída. Debes ver index.html, app.js, styles.css, otros archivos y las carpetas lib e icons.
  4. Mantén esa ventana abierta. Subirás todo el contenido de esa carpeta, conservando las carpetas lib e icons.

2. Crea el espacio en GitHub

  1. Entra a GitHub y crea una cuenta gratuita con Sign up. Confirma tu correo.
  2. Ya dentro, pulsa el + de arriba a la derecha y elige New repository.
  3. En Repository name, escribe tecma-despachos.
  4. Selecciona Public, activa Add README y pulsa Create repository.

El código de la app será público. Sube sólo los archivos de este proyecto. Tus CSV de trabajo, respaldos con RUT y PDF de despacho se cargan dentro de la app, no se suben al repositorio. Los archivos de ejemplo incluidos usarán los datos de prueba suministrados.

GitHub Pages es gratuito con repositorios públicos: instrucciones oficiales de GitHub.

3. Sube el proyecto

  1. Dentro del repositorio, pulsa Add file → Upload files.
  2. Desde la carpeta extraída, selecciona todos los archivos y las carpetas lib e icons, y arrástralos a GitHub. No arrastres el ZIP ni la carpeta exterior completa.
  3. Espera a que termine la carga. Baja y pulsa Commit changes. Si pregunta dónde guardar, deja seleccionada la rama main.
  4. Vuelve a Code. Debes ver index.html directamente en la lista, junto a lib e icons. Si ves sólo una carpeta y debes entrar en ella para encontrar index.html, los archivos quedaron un nivel más abajo: vuelve a subir el contenido en la raíz.

El archivo .nojekyll puede estar oculto en Windows. Si no se subió, en GitHub usa Add file → Create new file, escribe .nojekyll como nombre, deja el contenido vacío y guarda con Commit changes.

4. Enciende la página

  1. En tu repositorio, pulsa Settings.
  2. En el menú izquierdo, entra a Pages.
  3. En Build and deployment → Source, elige Deploy from a branch.
  4. En Branch, selecciona main; al lado, selecciona /(root). Pulsa Save.
  5. Espera unos minutos y actualiza esa página. Aparecerá Visit site. Ábrelo.
  6. Tu dirección tendrá esta forma: https://TU-USUARIO.github.io/tecma-despachos/. Copia la dirección real que muestra GitHub y envíatela al teléfono.

Configuración: fuente de publicación de GitHub Pages. La primera publicación puede tardar hasta 10 minutos. No necesitas dominio de pago.

5. Instala en tu Samsung / Android

  1. Abre la dirección publicada con Chrome, usando internet.
  2. Espera a ver arriba Lista para usar sin conexión.
  3. Toca los tres puntos ⋮ → Agregar a la pantalla principal o Instalar app, según tu versión.
  4. Confirma con Instalar o Agregar.
  5. Abre Tecma desde el nuevo ícono. Da permiso de cámara cuando decidas usarla.

Ayuda oficial de Chrome para instalar aplicaciones web.

6. Instala en iPhone

  1. Abre la dirección con Safari, usando internet.
  2. Toca Compartir (cuadrado con una flecha hacia arriba). Según la versión, está dentro del menú de la página.
  3. Busca Agregar a inicio o Agregar a pantalla de inicio.
  4. Si aparece Abrir como app web, déjalo activado. Toca Agregar.
  5. Abre el nuevo ícono Tecma y espera Lista para usar sin conexión antes de ir a fábrica. Empieza tus cargas desde este ícono.

Ayuda oficial de Safari en iPhone. Los nombres del menú pueden variar con la versión.

7. Haz una primera prueba

  1. Abre Nueva carga → Usar ejemplo de prueba. Aparecerán 3 obras y 8 productos.
  2. Pulsa Comenzar a escanear.
  3. En el ingreso manual, escribe 513042 y toca Agregar. Debe aparecer verde: CASA GILI · V05C.
  4. Repítelo: verás Ya escaneado en amarillo. No duplica el producto.
  5. Prueba 999999: verás rojo y la opción de agregar una línea manual.
  6. Lee 508270 y 513041. Verás avanzar GRENERGY y CASA GILI, respectivamente.
  7. En Obras, abre CASA GILI y toca el producto 513043. Cambia a No enviado, motivo Dañado, y guarda.
  8. En Agregar accesorio, escribe BURLETE COD: JF005, cantidad 100, unidad MT. Guarda.
  9. En Cierre y PDF, prueba ambos documentos de CASA GILI. El PDF para guías lleva sólo cargados y accesorios. El de control muestra también pendientes y motivos.
  10. Cuando arriba diga Lista para usar sin conexión, activa modo avión, cierra y vuelve a abrir Tecma desde su ícono. Comprueba que la carga sigue ahí y puedes seguir ingresando códigos.

8. Úsala en un despacho real

  1. Exporta desde Excel la lista de etiquetas como CSV UTF-8. Guarda el archivo en el teléfono. Si necesitas varias obras, puedes incluirlas en un archivo o seleccionar varios CSV.
  2. Crea Nueva carga, selecciona tus CSV, marca las obras que irán y completa los datos opcionales. Una carga corresponde a un camión.
  3. Conecta el lector Bluetooth desde los ajustes del teléfono. Configúralo en modo teclado / HID y con terminador Enter / CR. Esto se configura con el manual del lector.
  4. En la app toca Activar lector. Debe decir Lector listo. Los códigos aparecerán sin abrir el teclado del teléfono.
  5. También puedes usar Cámara o ingresar los números a mano. La cámara necesita ver el código completo y sus márgenes. La linterna se muestra si el teléfono permite controlarla.
  6. Marca lo que no va, agrega accesorios y completa atriles desde Obras.
  7. En Cierre y PDF, revisa cantidades y pulsa Cerrar carga. Si quedan pendientes, la app te avisará y podrás cerrar igual.
  8. Por cada obra, pulsa PDF para guías. En el cuadro que aparece, toca Compartir para elegir WhatsApp o correo. Si no está disponible, se descargará. El envío por WhatsApp o correo sí necesita internet.
  9. Usa PDF de control para tu registro y Códigos escaneados para volver a Excel.
  10. Al terminar, vuelve a Mis cargas → Exportar respaldo y guarda el JSON fuera del teléfono. Para cambiar de teléfono, instala Tecma y usa Importar respaldo.

Si algo no aparece como esperas

SituaciónQué hacer
GitHub muestra 404Espera la publicación y revisa main, /(root) e index.html en la raíz.
No dice «Lista para usar sin conexión»Conecta internet y vuelve a abrir. Revisa que se subieron ambas carpetas y todos los archivos.
El lector escribe pero no marcaActiva el lector en pantalla y configura Enter/CR al final de cada lectura.
No abre la cámaraAbre la dirección HTTPS en Chrome o Safari y permite cámara en los ajustes del sitio. Cierra otras apps que estén usando la cámara.
No vibra el iPhoneSafari puede no ofrecer vibración. Los avisos de color y texto siguen funcionando.
No se escuchaToca primero un botón de la app, revisa volumen y modo silencio. El guardado se confirma en pantalla.
Faltan cargas al cambiar de navegadorCada navegador o instalación guarda sus datos localmente. Importa un respaldo en el lugar donde seguirás trabajando.

No borres los datos del sitio ni desinstales la app sin exportar tus respaldos. El teléfono puede liberar almacenamiento local si le falta espacio. El aviso verde significa que la escritura terminó; un corte antes de esa confirmación exige revisar o repetir la lectura.

Actualizar la app más adelante

Antes de actualizar, exporta un respaldo. Sube los archivos nuevos al mismo repositorio. La nueva entrega debe cambiar también la versión en sw.js. Abre Tecma con internet, espera el aviso de actualización, cierra todas sus ventanas y vuelve a abrir. Mantén la misma dirección para conservar el almacenamiento de la app.
